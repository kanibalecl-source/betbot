BETBOT SERVER v20.2 - BASKETBALL DATE-SCOPE RECOVERY

Purpose:
- update the isolated basketball shadow runtime from 1.1 to 1.2
- continue a cycle when the provider restricts only a particular date
- retain fail-closed behavior for real authentication, quota, rate-limit,
  endpoint and whole-product access failures

Runtime behavior:
- an ENTITLEMENT application error after a successful date is classified as
  a date-scoped restriction and the next planned date is attempted
- if no date succeeds, three consecutive ENTITLEMENT errors open the circuit
- HTTP 401/403 AUTH_OR_ENTITLEMENT still opens the circuit immediately
- odds endpoint ENTITLEMENT errors still open the circuit immediately
- the existing 40-request budget remains enforced
