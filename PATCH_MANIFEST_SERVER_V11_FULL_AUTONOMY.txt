BETBOT SERVER v11 — FULL AUTONOMY, DATA-GATED LEARNING

CEL
---
Jeden bezpieczny cykl 24/7:
zbieranie -> rozliczanie -> Guardian -> jakościowy dataset -> Challenger
-> walk-forward -> live shadow -> Scorecard -> canary -> promocja/rollback.

NAJWAŻNIEJSZE ZMIANY
--------------------
1. Jeden właściciel retreningu: autonomous_quality_v11.
2. Stary AutoRetrainingRuntime nie jest już uruchamiany przez scheduler.
3. Scheduler nie duplikuje live pipeline ani persistence.
4. Persistence nie duplikuje procesu settlement.
5. Trening jest blokowany, dopóki Guardian nie potwierdzi:
   - minimum 300 rozliczonych obserwacji,
   - settlement coverage >= 95%,
   - closing odds coverage >= 80%,
   - brak krytycznych alertów.
6. Produkcyjne wagi segmentów powstają dopiero po minimalnej próbie,
   z regularizacją do wyniku globalnego.
7. Automatyczna promocja wymaga jednocześnie:
   - zdrowego Guardiana,
   - pozytywnego walk-forward,
   - pozytywnego live shadow,
   - potwierdzonego Statistical Evidence Scorecard,
   - identycznego SHA-256 kandydata w Scorecard,
   - świeżych etapów canary 10% -> 25% -> 50% -> 100%.
8. Po pogorszeniu jakości działa automatyczny rollback do poprzedniego Championa.
9. Panel pokazuje fazę automatyzacji, następny krok i stan rollbacku.

OCHRONA DANYCH
--------------
- Paczka NIE zawiera katalogu data ani żadnego pliku historii.
- Paczka NIE zawiera modeli, baz SQLite, CSV ani sekretów.
- Pliki na woluminie /data nie są usuwane ani zastępowane.
- Dataset treningowy, raporty i kandydaci są artefaktami pochodnymi.
- Historia źródłowa pozostaje append-only.
- BETTING_ENABLED i BETBOT_CAPITAL_REAL_ENABLED nie są zmieniane.
